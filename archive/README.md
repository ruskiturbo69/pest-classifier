# Archived experiments

The active project lives under `src/pest_classifier/` and targets IP102 with PyTorch.

This directory keeps earlier experiments for historical reference only:

- `classical_ml/` contains the former 9-class Random Forest/HOG/LBP pipeline,
- `prototypes/` contains early deep-learning scripts that were replaced by the current CLI.

Archived files are not part of the supported workflow and are not used by the tests or documentation.
