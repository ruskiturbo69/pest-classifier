- Paper: [CVPR 2019 Open Access](https://openaccess.thecvf.com/content_CVPR_2019/html/Wu_IP102_A_Large-Scale_Benchmark_Dataset_for_Insect_Pest_Recognition_CVPR_2019_paper.html)
- Dataset repository: [xpwu95/IP102](https://github.com/xpwu95/IP102)
- BibTeX key: `Wu_2019_CVPR`
